# Groundwork's WhatsApp profile images

- `groundwork-whatsapp-navy.png`: 640 x 640, navy background (#0C447C), the Groundwork mark alone in white.
- `groundwork-whatsapp-cream.png`: 640 x 640, cream background (#FDFBF6), the mark in navy.
- `groundwork-mark-original.svg`: a copy of the original mark, `client/public/favicon.svg` (three widening bars).

The mark is centred with a fifth of the width empty on every side (128 pixels), so it sits well inside the circle WhatsApp crops a profile picture to. Both were drawn from the original mark's own shapes, scaled, with nothing added.
