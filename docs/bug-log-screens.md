# Bug log: the screens

The screens workspace's bug log for the user journey sweep in `docs/user-journey-tests.md`. There is one row per problem, in the document's format. Faults in the engine's part go to the engine as requests in `docs/requests-to-engine.md`, and their rows here name the request.

**How serious**, in the order they are fixed: Privacy, Stops someone using it, Wrong information, Confusing, Cosmetic.

Screenshots are in `docs/page-audit/` (named `<number>-<page>-<role>-<width>.png`) or `docs/bug-log-screens/` (named after the bug). The deep page audit's (B-122 to B-171) are in `docs/page-audit/deep/` (named `<page>-<role>-<width>.png`, and `<page>~<tab>-<role>-<width>.png` for a tab), on this computer only.
